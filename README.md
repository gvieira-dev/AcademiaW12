# Academia W12

Site institucional da Academia W12, desenvolvido a partir de um template HTML e adaptado para apresentar a academia, seus serviços, informações de funcionamento e localização.

## Sobre o projeto

O projeto é uma página web estática, criada com HTML, CSS e JavaScript. A interface utiliza o Bootstrap para auxiliar na responsividade e na organização do layout.

O site possui:

- Página inicial com apresentação da academia;
- Página sobre a academia;
- Página de serviços;
- Página de funcionamento, endereço, contato e mapa;
- Imagens locais para compor o visual do site.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5.2.3;
- Google Maps Embed.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.

Para uma melhor experiência durante o desenvolvimento, utilize a extensão **Live Server** do VS Code e abra o projeto por meio dela.
